  • 加减乘
    • 尾数法
      • 精算，选项尾数不同
    • 划线加减
      • 多位数加减
    • 高位叠加
      • 多个数加和
    • 高位乘法
      • 多位数 × 一位数
    • 特殊数字
      • ×1.5 = 本身 + 一半
      • ×1.1 = 错位相加
      • ×0.9 = 错位相减
      • 百分数 ↔ 分数
    • 拆分
      • 因子近整数，或选项很近
    • 口诀
      • 两位数 × 两位数：前前后后
  • 除法
    • 截位直除
      • 差距大：截 2 位
      • 差距小：截 3 位
      • 差距极小：截 4 位
      • 一步除法：只截分母
      • 选项差 10 倍、100 倍：先看量级
    • 包子
      • 分母的 1% 为 1 个包子，看分子能买几个
    • 等比修正
      • 分子、分母同倍加减，分数值不变
    • 分数比较
      • 分子大、分母小 → 分数大
      • 同大同小：竖除，横看倍数
  • 基期
    • 计算
      • 问过去的量
      • 给增长量、r
        • 基期 = 增长量 / r
      • 给现期、增长量
        • 基期 = 现期 − 增长量
      • 给现期、r
        • 基期 = 现期 / (1+r)
        • |r|≤5%：A/(1+r) ≈ A(1−r)
        • |r|≤5%：A/(1−r) ≈ A(1+r)
      • 和差
        • A/(1+a) ± B/(1+b)
      • 复杂·给主体 r
        • 部分现期 = 总体 × 比重
        • 基期 = 部分现期 / (1+r)
      • 复杂·不给主体 r
        • 部分基期 = 总体基期 × 基期比重
        • 总体基期 = 部分基期 / 基期比重
    • 比较
      • 问过去谁大
      • 给现期、增长量
        • 基期 = 现期 − 增长量
      • 给现期、r
        • 现期大且 r 小 → 基期大
  • 现期
    • 追赶
      • 保持增量，哪年 A 超过 B
      • 追固定数
        • n = 差距 / 增长量
        • 不整，往大取
        • 年份 = 基期年 + n
      • 小追大
        • n = 差距 / 增长量差
        • 不整，往大取
    • 保持增量
      • 现期 = 基期 + 增长量 × n
      • 五年和 S5 = 5 × 中项
      • 差距 = 原差距 + 增长量差 × n
    • 保持 r
      • 现期 = 基期 × (1+r)
      • n 年：现期 = 基期 × (1+r)^n
      • 不给 r·给增量
        • r>0：下一年增量更大
      • 不给 r·给现期基期
        • 倍数明显：乘倍数
  • 增长量
    • 计算
      • 问增长多少
      • 给基期、r
        • 增长量 = 基期 × r
        • 每增 N 个百分点 = 基期 × N%
      • 给现期、基期
        • 增长量 = 现期 − 基期
      • 年均
        • 年均增长量 = (现期 − 基期) / 年份差
      • 给现期、r
        • 增长量 = 现期 / (1+r) × r
        • |r|≤5%：≈ 现期 × r
        • |r|=1/n：增量 = 现期 / (n+1)
        • |r|=1/n：减量 = 现期 / (n−1)
      • 混合
        • 总体增量 = Σ 部分增量
      • 倍数
        • |a−b|≤10 个百分点：增量比 ≈ 现期比 × r 比
    • 比较
      • 问谁增得最多
      • 柱：高度差。折线：斜率
      • 现期大且 r 大 → 增量大
      • 下降越多，增量越小
      • 贡献率 = 部分增量 / 总体增量
  • 一般增长率
    • 计算
      • 问增长的比例
      • 给现期 r、百分点
        • 高减低加
        • 增速、增幅：带符号
        • 降幅：先取绝对值，再加负号
      • 给现期、基期、增量，任两个
        • r = 增长量 / 基期
        • r = (现期 − 基期) / 基期
        • r = 现期 / 基期 − 1
        • r = 增长量 / (现期 − 增长量)
      • 特定·给现期、基期
        • r>10% → 现期 > 1.1 × 基期
        • r>50% → 现期 > 1.5 × 基期
      • 特定·给现期、增量
        • (n+1) × 增长量 > 现期
        • r>100% → 2 × 增长量 > 现期
    • 比较
      • 问谁最快、最慢
      • 给现期、基期
        • 倍数差明显：倍数大 → r 大
        • 不明显：增长量大、基期小 → r 大
        • 再比：增长量 / 基期
      • 给现期、增量
        • 比 增长量 / 现期
        • 只用于比较
    • 易错
      • 增幅：带正负号比
      • 降幅、变化幅度：比 |r|
      • 增长几倍 = r
      • 是几倍 = r + 1
      • r = 是几倍 − 1
      • 增长 1 倍 = 100% = 是 2 倍
      • 增长 1.2 倍 = 120% = 是 2.2 倍
      • r = 20% → 是 1.2 倍
  • 间隔
    • 间隔 r
      • 隔一期，问比例
      • r间 = r1 + r2 + r1×r2
    • 间隔倍数
      • 是几倍 = r间 + 1
      • 多几倍 = r间
    • 间隔基期
      • 基期 = 现期 / (1+r间)
    • 间隔现期
      • 现期 = 基期 × (1+r间)
    • 间隔增量
      • 先 r间，再按增长量百化分
    • 间隔多年
      • 各年 r>0：r间 > r1+r2+r3+…
      • r间 > 年均 r × 年份差
    • 逆求
      • r2 = (r间 − r1) / (1+r1)
      • 已知平均 r：先 r间 = r+r+r×r
  • 年均 · 乘积
    • 年均·比较
      • 年份差相同
      • 比 现期 / 基期
      • 总 r 大 → 年均 r 大
    • 年均·计算
      • (1+r)^n = 现期 / 基期
      • 选项大多 <10%：r < 总 r / n
      • 选项大多 ≥10%：代入整十
    • 乘积
      • A = B × C
      • rA = rB + rC + rB×rC
      • rC = 0 → rA = rB
      • 总额 = 单价 × 数量
      • 产量 = 单产 × 面积
      • 部分 = 总体 × 比重
  • 混合增长率
    • 识别
      • 部分 + 部分 = 总体
      • 进出口 = 进口 + 出口
      • 顺差 = 出口 − 进口
      • 总体 = A + 非 A
    • 居中
      • r小 < r总 < r大
    • 偏向
      • 靠近基期量大的一侧
    • 线段
      • 距离与基期量成反比
    • 三角杀
      • Δ = r大 − r小
      • 量比 = 基期大 / 基期小
      • 混合到较大 r 的距离 = Δ / (量比 + 1)
    • 反例
      • 两 r 差大：必须用基期量
    • 当月·累计
      • 当月 r > 累计 r → 累计 r 上升
      • 当月 r < 累计 r → 累计 r 下降
  • 比重
    • 识别
      • ……占……
      • 利润率 = 利润 / 收入
      • 产销率 = 销量 / 产量
      • 贡献率 = 部分增量 / 总体增量
    • 现期
      • A 占 B = A / B
      • A 中 B = B / A
      • 部分 = 总体 × 比重
      • 总体 = 部分 / 比重
      • 同总体：比重差 = 部分差 / 总体
      • A占B = m，B占C = n → A占C = m×n
    • 基期
      • 给增量：(部分−部分增量) / (总体−总体增量)
      • 给 r：A/B × (1+b)/(1+a)
    • 两期
      • a > b → 比重上升
      • a < b → 比重下降
      • 比重上升 → a > b
      • 两期比重差 = A/B × (a−b)/(1+a)
  • 平均数
    • 识别
      • 均、每
      • 单价、亩产、单位利润
    • 现期
      • 平均数 = 后 / 前
      • 总数 = 平均数 × 个数
      • 比大小：分数比较
    • 基期
      • 给增量：(分子−分子增量) / (分母−分母增量)
      • 给 r：A/B × (1+b)/(1+a)
    • 两期
      • a > b → 平均数上升
      • a < b → 平均数下降
      • 平均数增长量 = A/B × (a−b)/(1+a)
      • 平均数增长率 = (a−b)/(1+b)
  • 倍数与比例
    • 现期
      • 是几倍 = A / B
      • 多几倍 = A/B − 1
      • 多 N 倍以上：(A/B) − 1 ≥ N
      • 超过 N 倍：A/B > N
      • 超过 N 倍 → A > N × B
    • 平均数的倍数
      • (A1/B1) / (A2/B2)
      • = (A1/A2) / (B1/B2)
    • 基期
      • 给增量：(分子−增量) / (分母−增量)
      • 给 r：A/B × (1+b)/(1+a)
    • 混合
      • (A+B+…) / (D+E+…)
      • 居中，偏向分母量大的一侧
      • 当月 > 累计月均 → 当月 > 前几月月均
  • A 与非 A · 综合
    • 量
      • A + 非 A = 总体
      • 非 A = 总体 − A
      • 增量同样相加
    • 率
      • 总体 r：混合，居中
    • 比例
      • A 比重 + 非 A 比重 = 1
      • 占比 > 50% → A > 非 A
      • 占比 > 66.7% → A > 2 × 非 A
      • 占比 > 75% → A > 3 × 非 A
      • A = 2 × 非 A → 占比 ≈ 66.7%
      • A = 3 × 非 A → 占比 = 75%
    • 综合
      • 先：两期比例、混合、A 与非 A
      • 均、都、逐年、首超：易错
      • 约：易对
      • 多几倍 ≠ 是几倍
      • 顺序：找数 → 加减 → 一步除 → 增量 → r → 基期或两期比例
