  • 加减乘
    • 尾数法
      • 精算，尾数不同
      • 算尾数，看选项
      • 判断正负
    • 划线加减
      • 精算、估算
      • 截位划线，算前看后
      • 位数不变：写 N+、N−
    • 高位叠加
      • 多个数加和
      • 高位加起，进位另加
      • 两加一估：计算估 5，范围估 10
    • 高位乘法
      • 多位数 × 一位数：高位乘起，最后叠加
    • 特殊数字
      • ×1.5 = 本身 + 一半
      • ×1.1 = 错位相加
      • ×0.9 = 错位相减
      • 百化分：百分数 ↔ 分数，乘除互化
    • 拆分
      • 因子近整数，或选项差距小
      • 先凑整，再看误差
    • 口诀
      • 两位数 × 两位数：前前后后，里里外外
  • 除法
    • 截位直除
      • 差距大，首位不同：截 2 位
      • 首位同、第二位差 > 首位：截 3 位
      • 临界值（如 59 与 61）：截 3 位
      • 第二位差 ≤ 首位，或前两位同：截 4 位
      • 一步除法：截分母，直除
      • 多步除法：截分子、分母，约分
      • 选项差约 10 倍、100 倍：先看量级
    • 包子
      • 分母的 1% 为 1 个包子，看分子能买几个
    • 等比修正
      • 分子、分母同倍加减，分数值不变
    • 分数比较
      • 分子大、分母小 → 分数大
      • 同大同小：竖除，横看倍数
  • 基期
    • 计算
      • 问过去的量
      • 给增长量、r
        • 基期 = 增长量 / r
      • 给现期、增长量
        • 基期 = 现期 − 增长量
      • 给现期、r
        • 基期 = 现期 / (1+r)
        • 差距大：直除 2 位
        • 差距小：直除 3 位
        • |r|≤5%：A/(1+r) ≈ A(1−r)
        • |r|≤5%：A/(1−r) ≈ A(1+r)
        • 差距极小：直除 4 位
      • 和差
        • A/(1+a) ± B/(1+b)
        • 算一半，看一半
        • 等比修正，分母化同
      • 复杂·给主体 r
        • 部分现期 = 总体 × 比重
        • 基期 = 部分现期 / (1+r)
      • 复杂·不给主体 r
        • 部分基期 = 总体基期 × 基期比重
        • 总体基期 = 部分基期 / 基期比重
    • 比较
      • 问过去谁大
      • 给现期、增长量
        • 基期 = 现期 − 增长量
        • 找现期最大做参照
      • 给现期、r
        • 基期 = 现期 / (1+r)
        • 现期大、r 小 → 基期大
        • 再比：分数比较
  • 现期
    • 追赶
      • 保持增量，哪年 A 超过 B
      • 追固定数
        • n = 差距 / 增长量
        • 不整，往大取
        • 年份 = 基期年 + n
      • 小追大
        • n = 差距 / 增长量差
        • 不整，往大取
    • 保持增量
      • 现期 = 基期 + 增长量
      • 等差：S5 = 5 × 中项
      • 非等差：先按等差求和，再修误差
      • 差距 = 原差距 + 增长量差 × n
    • 保持 r
      • 现期 = 基期 × (1+r)
      • n 年：现期 = 基期 × (1+r)^n
      • 选项近：特殊数字，拆分
      • r<0：减少量变小
      • 不给 r·给增量
        • 按增量推：结果偏小，选大
      • 不给 r·给现期基期
        • 倍数明显：乘倍数
        • 不明显：按增量推，结果偏小选大
  • 增长量
    • 计算
      • 问增长多少
      • 给基期、r
        • 增长量 = 基期 × r
        • 每增 N 个百分点 = 基期 × N%
      • 给现期、基期
        • 增长量 = 现期 − 基期
        • 多个数：先减再加，或先加再减
        • 时间段首年有数，必须验证
      • 年均
        • 年均增长量 = (现期 − 基期) / 年份差
        • 普通：基期不前推
        • 江苏：基期前推一年
        • 五年规划：年份差 = 5，基期前推一年
      • 给现期、r
        • 增长量 = 现期 / (1+r) × r
        • |r|≤5% 且选项差距大：≈ 现期 × r
        • 估增量偏大，估减量偏小
        • |r|=1/n：增量 = 现期 / (n+1)
        • |r|=1/n：减量 = 现期 / (n−1)
        • 误差 = 基期 × r 的差值
      • 混合
        • 总体增量 = 部分增量 + 部分增量 + …
        • 有升有降：先抵消
      • 倍数
        • |a−b|≤10 个百分点：A增量/B增量 ≈ (A/B)×(a/b)
        • |a−b|>10 个百分点：分别百化分，再比倍数
    • 比较
      • 问谁增得最多、最少
      • 增长量 = 现期 − 基期
      • 柱：高度差。折线：斜率
      • 趋势：先正负，再大小，再比例
      • 现期大且 r 大 → 增量大
      • 一大一小：百化分后再比
      • 下降越多，增量越小
      • 变化量：比 |增长量|
      • 贡献率 = 部分增量 / 总体增量
      • 同一总体：直接比部分增量
  • 一般增长率
    • 计算
      • 问增长的比例
      • 给现期 r、百分点
        • 高减低加
        • 增速、增幅：带符号
        • 降幅：先取绝对值，再加负号
      • 给现期、基期、增量，任两个
        • r = 增长量 / 基期
        • r = (现期 − 基期) / 基期
        • r = 现期 / 基期 − 1
        • r = 增长量 / (现期 − 增长量)
      • 特定·给现期、基期
        • r>10% → 现期 > 1.1 × 基期，错位相加
        • r>50% → 现期 > 1.5 × 基期，本身 + 一半
        • 或看前三位，口算增长量
      • 特定·给现期、增量
        • (n+1) × 增长量 > 现期
        • r>100% → 2 × 增长量 > 现期
    • 比较
      • 问谁最快、最慢
      • 给现期、基期
        • 倍数差明显：倍数大 → r 大
        • 不明显：增长量大、基期小 → r 大
        • 再比：增长量 / 基期
        • 柱：高度差占柱子比例越大，r 越大
        • 只用于比较
      • 给现期、增量
        • 比 增长量 / 现期
        • 只用于比较
    • 易错
      • 增幅：带正负号比
      • 降幅、变化幅度：比 |r|
      • 增长几倍 = r
      • 是几倍 = r + 1
      • r = 是几倍 − 1
      • 增长 1 倍 = 100% = 是 2 倍
      • 增长 1.2 倍 = 120% = 是 2.2 倍
      • r = 20% → 是 1.2 倍
  • 间隔
    • 间隔 r
      • 隔一期，问比例
      • r间 = r1 + r2 + r1×r2
    • 间隔倍数
      • 是几倍 = r间 + 1
      • 多几倍 = r间
    • 间隔基期
      • 差距大：r间 估到十位
      • 差距小：r间 估到个位
      • 基期 = 现期 / (1+r间)
    • 间隔现期
      • 现期 = 基期 × (1+r间)
    • 间隔增量
      • 先 r间，再按增长量百化分
    • 间隔多年
      • 各年 r>0：r间 > r1+r2+r3+…
      • r间 > 年均 r × 年份差
    • 逆求
      • r2 = (r间 − r1) / (1+r1)
      • 已知平均 r：先 r间 = r+r+r×r
  • 年均 · 乘积
    • 年均·比较
      • 年份差相同
      • 比 现期 / 基期
      • 总 r 大 → 年均 r 大
    • 年均·计算
      • (1+r)^n = 现期 / 基期
      • 选项大多 <10%：r < 总 r / n
      • 选项大多 ≥10%：代入整十
    • 乘积
      • A = B × C
      • rA = rB + rC + rB×rC
      • rB = 0 → rA = rC
      • 总额 = 单价 × 数量
      • 产量 = 单产 × 面积
      • 部分 = 总体 × 比重
      • 城镇收入 = 农村收入 × 倍差
      • 不变、相同：对应的 r = 0
  • 混合增长率
    • 识别
      • 进出口 = 进口 + 出口
      • 全国 = 城镇 + 农村
      • 邮电 = 邮政 + 电信
      • 本外币 = 人民币 + 外币
      • 全年 = 1–11月 + 12月
      • 一季度 = 1–2月 + 3月
      • 出口 = 进口 + 顺差
      • 进口 = 出口 + 逆差
      • 收入 = 支出 + 盈余
      • 总体 = A + 非 A
    • 居中
      • r小 < r总 < r大
    • 偏向
      • 偏向基期量大的一侧
    • 线段
      • 距离与量成反比
      • 距离 = 部分 r − 总体 r
      • 量 = 部分基期
    • 三角杀
      • Δ = r大 − r小
      • 量比 = 基期大 / 基期小
      • 大：除。小：乘。混合：÷ (量比+1)
      • 求部分 r：距离对混合 r
      • 求混合 r：距离对较大的部分 r
    • 反例
      • 部分 r 差大：口诀、线段、三角杀都用基期
    • 当月·累计
      • 当月 r > 累计 r → 累计 r 上升
      • 当月 r < 累计 r → 累计 r 下降
    • 多者
      • 仍居中、偏向
      • 拆成两两。先等量，先接近的 r
  • 比重
    • 识别
      • ……占……的比重
      • 利润率 = 利润 / 收入
      • 贡献率 = 部分增量 / 总体增量
      • 亏损面 = 亏损企业 / 全部企业
      • 城镇化率 = 城镇人口 / 总人口
      • 产销率 = 销量 / 产量
    • 现期
      • A 占 B = A / B
      • A 中 B = B / A
      • 同总体：比重差 = 部分差 / 总体
      • 不同总体：分别求，再相减
      • 超过某比重的个数：总体 × 该比重，再数大于乘积的
      • 饼图：部分/总体 = 1/2、1/3、1/4
      • 饼图：部分/部分 = 2 倍、3 倍
      • 类比：部分是几倍，比重是几倍
      • A占B = m，B占C = n → A占C = m × n
      • 总体 = 部分 / 比重
      • 部分 = 总体 × 比重
    • 基期
      • 给增量：(部分−部分增量) / (总体−总体增量)
      • 给 r：A/B × (1+b)/(1+a)
    • 两期
      • a > b → 比重上升
      • a < b → 比重下降
      • 比重上升 → a > b
      • 比重下降 → a < b
      • 两期比重差 = A/B × (a−b)/(1+a)
  • 平均数
    • 识别
      • 均、每
      • 单价、亩产、单位利润
    • 现期
      • 平均数 = 后 / 前
      • 总数 = 平均数 × 个数
      • 比大小：分数比较，看量级
      • 超过某值的个数：注意量级
      • 月均、日均：谁好除先除谁
      • 多个数：凑整或高位叠加，再除
      • 类比：分子是几倍，平均数是几倍
    • 基期
      • 给增量：(分子−分子增量) / (分母−分母增量)
      • 给 r：A/B × (1+b)/(1+a)
    • 两期
      • a > b → 平均数上升
      • a < b → 平均数下降
      • 平均数增长量 = A/B × (a−b)/(1+a)
      • 平均数增长率 = (a−b)/(1+b)
  • 倍数与比例
    • 现期
      • A 是 B 的几倍 = A / B
      • A 为 B 的几倍 = A / B
      • A 与 B 的比例 = A : B
      • 多几倍 = A/B − 1
      • 多 N 倍以上：(A/B) − 1 > N
      • 超过 N 倍：A/B > N → A > N × B
    • 平均数的倍数
      • 比例倍数 = 分子倍数 / 分母倍数
      • (A1/B1) / (A2/B2) = (A1/A2) / (B1/B2)
    • 基期
      • 给增量：(部分−部分增量) / (总体−总体增量)
      • 给 r：A/B × (1+b)/(1+a)
    • 混合
      • (A+B+C+…) / (D+E+F+…)
      • 当月 > 累计月均 → 当月 > 前几月月均
      • 当月 < 累计月均 → 当月 < 前几月月均
      • 求人数比：距离与量成反比，量是人数
  • A 与非 A · 综合
    • 量
      • A + 非 A = 总体
      • 非 A = 总体 − A
      • A 增量 + 非 A 增量 = 总体增量
    • 率
      • 混合：居中、偏向
      • 线段：量之比 = 基期之比
    • 比重
      • 线段：量之比 = 总体之比
      • 占比 50% → A = 非 A
      • 占比 66.7% → A = 2 × 非 A
      • 占比 75% → A = 3 × 非 A
      • 倍数越大，占比越大
    • 平均数
      • 混合平均数：居中、偏向
      • 线段：量之比 = 分母之比
    • 倍数
      • A = 2 × 非 A → 占比 ≈ 66.7%
      • A = 3 × 非 A → 占比 = 75%
    • 综合
      • 先看：两期比例、混合范围、A 与非 A
      • 算非 A：先算 A
      • 均、都、同一个、逐年、首超：易错
      • 约：易对
      • 多几倍 ≠ 是几倍
      • 日均、月均：要除天数、月数
      • 顺序：找数 → 加减 → 一步除 → 增量 → r → 基期或两期比例
